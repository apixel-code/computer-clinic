# Computer Clinic Website - Technical Documentation

## 🎨 Design Features

- **Dark Tech Theme**: Dark navy/charcoal background (#1a1a2e) with cyan (#00bcd4) and orange (#ff6600) accents
- **Animations**: Framer Motion powered animations throughout
  - Animated hero section with particle effects
  - Scroll-triggered fade-ins
  - Hover effects on cards and buttons
  - Smooth page transitions
  - Number counter animations
- **Responsive Design**: Fully mobile-responsive layout
- **Modern UI**: Clean, professional design with glassmorphism effects

## 📄 Pages

1. **Home** (`/`) - Animated hero, services, stats, testimonials
2. **Services** (`/services`) - 7 detailed service offerings
3. **About** (`/about`) - Company history, mission, timeline
4. **Testimonials** (`/testimonials`) - Client reviews and ratings
5. **Contact** (`/contact`) - Contact form, map, business info
6. **Blog** (`/blog`) - Placeholder blog posts

## 🛠️ Tech Stack

**Frontend**: React 19, Framer Motion, Tailwind CSS, Shadcn UI
**Backend**: FastAPI, MongoDB, Pydantic
**Features**: Sticky nav, floating WhatsApp, contact form with DB storage

## 📊 API Endpoints

- `POST /api/contact` - Submit contact form
- `GET /api/contact-submissions` - Get all submissions
